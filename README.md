# ServiceCenter

Учебная конфигурация 1С:Предприятие 8.3 для автоматизации деятельности сервисного центра по ремонту техники.

## Назначение

Система предназначена для ведения полного цикла работ сервисного центра.

## Ролевая модель

В конфигурации реализованы следующие роли:
- ПолныеПрава (техническая роль)
- Администратор
- Приёмщик
- Мастер
- Кладовщик
- Бухгалтер

Права доступа разграничены по принципу минимальных привилегий. Мастер имеет доступ только к своим заявкам. Управление ценами и персоналом доступно администратору.

## Требования к запуску

- Платформа: 1С:Предприятие 8.3.
- Среда разработки: Конфигуратор.
- Контроль версий: Git.

## Порядок запуска

1. Создать новую информационную базу в 1С:Предприятие 8.3.
2. Открыть Конфигуратор.
3. Загрузить конфигурацию из файлов или из файла выгрузки.
4. Обновить конфигурацию базы данных.
5. Запустить 1С:Предприятие.
